# 3D rendering

Moon Engine draws real 3D with [Foxlite](https://github.com/dwdvIl/foxlite), a hardware accelerated 3D renderer for HaxeFlixel. Since Moon Engine 0.2.0 it uses Foxlite 0.2.9 and the 3D is turned on in desktop builds (Windows, Linux and macOS).

A 3D scene is drawn by the graphics card into a texture, and that texture is a normal Flixel sprite in the state. So the 3D works with the cameras, the shaders, the tweens and the layering of the game like any other sprite, and sprites can be in front of it and behind it.

## Coordinates

The 3D world uses the convention of OpenGL and Blender: **Y is up** and the camera looks toward **negative Z**. A camera at `z = 9` looks at things that are at `z = -6`. `pitch` (angle X) is positive when the camera looks up, and `yaw` (angle Y) turns it left and right. A model exported from Blender keeps its orientation.

## Turning it on

- **Build.** The flag `FEATURE_3D_RENDERING` is on for desktop C++ builds (`project.hxp`). Mobile and web builds do not have it yet, because the Foxlite shaders have not been tested on OpenGL ES here. Without the flag nothing of the 3D is compiled and the Lua functions answer that 3D is not available (`is3DAvailable()` is `false`).
- **Options.** *Options > Preferences > 3D Mode* turns the 3D background of the main menu on and off. It is off in old saves and can be turned on in the menu.
- **Songs.** A song turns the 3D on from a Lua script (see below) or from the stage code with `PlayState.instance.enable3D()`.

## What the main menu does

With *3D Mode* on, the main menu has a lit 3D scene between the background and the menu: a ring and a core that pulse with the beat, six orbs around them, pillars, colored lights that change with the music, and a floor grid. It is built by `MenuBackdrop3D` and is a good example of how to build a scene.

If the 3D cannot start, the menu turns *3D Mode* off, writes the reason in the log and keeps working without it.

## The `Funkin3D` class

`funkin.graphics.render3d.Funkin3D` wraps a Foxlite scene and a camera. `FunkinCamera.attach3DScene(width, height)` makes one for a camera and `PlayState.enable3D(layer)` makes one for a song.

```haxe
var gfx = camera.attach3DScene(FlxG.width, FlxG.height);

gfx.setAmbient(0xFF404050);
gfx.addDirectionalLight(0xFFFFFFFF, 1.0, -45, 30);
gfx.addPointLight(-3, 2, 0, 0xFFFF4D9E, 2.0, 12);

var ring = gfx.addTorus(3, 0.3, 0xFFFFD166, 48, 16, 0, 0.5, -6, 'ring');

gfx.setCameraPosition(0, 1.6, 9);
gfx.lookAt(0, 0.5, -6);

add(gfx.scene);
```

| Method | What it does |
| --- | --- |
| `addBox`, `addSphere`, `addCylinder`, `addTorus`, `addPlane` | Lit shapes with a color. Each returns the model, which has `position`, `rotation` (`angleX/Y/Z` in degrees) and `scale` |
| `addGrid(size, divisions, color, y)` | A grid of lines |
| `loadModel(key)` | Loads a `.glb`, `.gltf` or `.obj` model by key (see *Models*) |
| `loadGLTFModel(path)`, `loadGLTFBinary(path)` | Loads a model from an explicit asset path |
| `addDirectionalLight`, `addPointLight` | Lights. `energy` is the strength and a point light has a `range` |
| `setAmbient`, `setFog`, `setBackground` | The light everywhere, the fog and the background of the scene |
| `setCameraPosition`, `setCameraAngle`, `setCameraFov`, `lookAt` | The camera |
| `useOrbitCamera(distance)` | Replaces the camera with an orbit camera that the mouse controls |
| `get(name)`, `findObjectByName(name)` | Finds an object by the name it was given or that a model file gave it |
| `createMaterial(color, lit, roughness, metallic, emissive)` | A material for your own meshes. `Mesh3D.sphere/cylinder/torus` build meshes from geometry |

Objects made by the helpers have no frustum culling, because scenes of a game are small. Set `model.frustumCulling = true` on a big world to get it back.

Shape geometry is generated by `MeshGeometry` (spheres, cylinders and tori, with normals and texture coordinates), which has no dependency on Foxlite and is covered by `tests/MeshGeometryTests.hx`.

## From Lua

Every function is in `LUA_API.md`, in the section *3D scenes*. A short script:

```lua
function onCreate()
  if not is3DAvailable() then return end

  enable3D()
  set3DAmbient('#40445A')
  add3DLight('sun', 'directional', 0xFFFFFFFF, 1.2, -45, 25)
  make3DTorus('ring', 2.5, 0.35, '#FFD166', 0, 0.5, -6)
  set3DCamera(0, 1.5, 9, -5, 0, 0)
end

function onUpdate(elapsed)
  set3DRotation('ring', 70, getSongPosition() * 0.05, 0)
end
```

Objects are tweened by putting `3d:` before the id: `doTween('t', '3d:ring', {y = 2}, 0.3, 'quadOut')`.

## Models

Models are looked up by key, in this order, and the first one that exists wins:

1. `assets/gameplay/models/<key>.<ext>`
2. `assets/ui/models/<key>.<ext>`
3. `assets/models/<key>.<ext>`

with the extensions `glb`, `gltf` and `obj`, in that order. Mods use the same paths without the `assets/` (for example `gameplay/models/arena.glb` inside the mod folder) and replace the game files, so a mod can change a model of the game and add new ones. A key with `..` in it is refused. The textures of a glTF model are loaded from the folder of the model. A texture asked for by name (`FoxTexture.fromImage('name')`) is looked for in `gameplay/textures`, `ui/textures` and `textures` first, and then where Foxlite looks by default.

glTF 2.0 is supported with materials, textures, skeletons, animations and lights, and binary `.glb` files and embedded buffers work. Blender exports it. See `docs/ASSET_PATHS.md` for the whole path system.

## Writing your own shaders

Foxlite keeps its shaders in `assets/shaders/foxlite/`. A mod can replace any of them, or add new ones that a material asks for by name, by putting a file with the same path in the mod. Materials push values to a shader, so one material works with any shader.

## Performance and limits

- The renderer needs OpenGL 3.0 or newer, like the rest of the game.
- A mesh can have 65,535 vertices. The shape helpers stay far under that.
- Foxlite has a limit of lights per scene: 4 directional, 16 point, 8 spot and 8 area lights.
- Lights with shadows are heavy. Shadows are off in everything Moon Engine builds.
- Lua scripts can make at most 512 3D objects each.

## Troubleshooting

- **Nothing is drawn.** Check that `enable3D()` ran before the objects were made, that the camera looks at them (`set3DLookAt`), and that the song script has no error in the log.
- **Everything is black.** There is no light. Add `set3DAmbient` or a light.
- **A model is not found.** `has3DModel(key)` and `list3DModels()` say what the game sees. The log says `Model "key" was not found`.
- **The menu stays without the 3D.** *3D Mode* was turned off by itself after an error. The reason is in the log. Turn it on again in the options.
